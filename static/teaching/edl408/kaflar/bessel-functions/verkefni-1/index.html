Bessel-föll¶

Við rekumst reglulega á Bessel-föll í eðlisfræði en fæst okkar geta sagt mikið um eiginleika þessara falla. Í þessari vinnubók reynum við aðeins að bæta úr því.

Bessel-föllin skjóta upp kollinum þegar við vinnum með diffurjöfnur eins og bylgju- eða hitajöfnununa í sívalningshnitum. Þau eru lausn á diffurjöfnunni:

$$ x^2 y'' + xy' + (x^2 - n^2)y = 0, $$

þar sem við köllum $n$ vísi Bessel-fallsins.

Þetta er 2. stigs diffurjafna og fyrir gefið gildi á $n$ eru tvær óháðar lausnir sem við köllum $J_n(x)$ og $N_n(x)$. Fallið $J_n(x)$ er kallað Bessel-fall af fyrstu gerð og $N_n(x)$ er kallað Bessel-fall af annarri gerð.

Skoðum fallið Bessel-fall af fyrstu gerð með vísinn $n=0$, þ.e.a.s: $J_0(x)$

Við getum flett upp í töflu og séð að fyrstu rætur þessa falls eru 2.4048, 5.5201, 8.6537, o.s.frv.

Skrifið stuttan kóða sem sækir þessar rætur fyrir $J_{n=0}(x)$. Köllum ræturnar $x_{nm} = x_{0m}$ þar sem $m = 1, 2, 3, \ldots$.

Finnið mismuninn á milli róta, þ.e.a.s. $\Delta x_{01} \equiv x_{01} - x_{00}$, $\Delta x_{02} \equiv x_{02} - x_{01}$, o.s.frv.

Airy mynstur¶

Við rekumst á Bessel-fall í frumeinda- og ljósfræði. Sjá t.d. umfjöllun í Kafla 5 í Introduction to Modern Optics (Dover).

Bylgjubrot (e. diffraction) fyrir hringlaga ljósop gefur það sem við köllum Airy mynstur.

$$ I(\theta) = = I_0 \left( \frac{2 J_1(ka \sin \theta )}{ka \sin\theta } \right)^2 = I_0 \left( \frac{2 J_1(x)}{x} \right)^2 $$

Við getum lesið um Airy mynstur hér: https://en.wikipedia.org/wiki/Airy_disk

þar sem $J_1(x)$ er Bessel-fall af fyrstu gerð með vísi $n=1$, $k = 2\pi / \lambda$ er bylgjutalan og $a$ er radíus ljósops.

Þetta fall lýsir styrkleika ljóss sem fall af staðsetningu þegar ljós brotnar á hringlaga rauf (t.d. ljósopi). Við getum framkallað svona mynstur þegar við beinum leiserljósi að hringlaga opi með þvermál $d = 2a$ þar sem $d$ er sambærilegt við öldulengd ljóssins $\lambda$ og mörg okkar hafa prófa þessa tilraun í verklegri eðlisfræði.

def drum_mode(n, m, R=1.0, Nr=300, Ntheta=400, angular="cos"):
    '''
    Reiknum eiginföll bylgjujöfnunnarí sívalningshnitum

    Breytur
    ----------
    n : int
        Vísir Bessel fallsins (n >= 0).
    m : int
         rót m (m >= 1).
    R : float
        Radíus trommunnar.
    Nr : int
        Fjöldi punkta radíalt
    Ntheta : int
        Fjöldi punkta eftir theta
    angular : str
        'cos' eða 'sin' eiginföll

    Skilar
    -------
    X, Y, Z : 2D fylki

        Fylki sem tákna XY hnit

    '''
    if n < 0 or m < 1:
        raise ValueError("Require n >= 0 and m >= 1")

    # nth zero of J_m
    alpha_nm = jn_zeros(n, m)[-1]

    r = np.linspace(0, R, Nr)
    theta = np.linspace(0, 2 * np.pi, Ntheta)

    # Meshgrid býr til tvívítt fylki frá tveimur vigrum r og theta
    rr, tt = np.meshgrid(r, theta, indexing="xy")

    # Reiknum Bessel fallið
    radial = jv(n, alpha_nm * rr / R)

    if angular == "cos":
        angular_part = np.cos(n * tt)
    elif angular == "sin":
        angular_part = np.sin(n * tt)
    else:
        raise ValueError("angular must be 'cos' or 'sin'")

    Z = radial * angular_part

    X = rr * np.cos(tt)
    Y = rr * np.sin(tt)

    return X, Y, Z

def plot_mode_2d(ax, n, m, R=1.0, angular='cos', cmap='RdBu_r'):
    X, Y, Z = drum_mode(n, m, R=R, angular=angular)

    pcm = ax.pcolormesh(X, Y, Z, shading='auto', cmap=cmap)
    ax.set_aspect('equal')
    ax.set_title(f'n={n}, m={m}, {angular} ($n \\theta$)')
    ax.set_xlabel('x')
    ax.set_ylabel('y')

    # Teiknum jaðarinn
    t = np.linspace(0, 2*np.pi, 500)
    ax.plot(R * np.cos(t), R * np.sin(t), 'k-', lw=1)

    return pcm
