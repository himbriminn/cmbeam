Skref 3¶
Numpy vigrar eru af tegundinni ndarray (sjá fyrir neðan):
















print('The Numpy array A is of type: {}'.format(type(A)))

















The Numpy array A is of type: <class 'numpy.ndarray'>

















Hér höfum við reitt okkur á innbygða Python fallið type. Við vitum jafnframt að Python hlutir (e. object) eru venjuleg með einhvers konar eigind eða eiginleika (e. attribute) og aðgerðir (e. method).


Notið dtype eigindina (e. attribute) til þess að komast að því hvers konar nákvæmni (e. precision) er notuð fyrir hverja tölu sem er geymd í þessu fylki. Notið svo astype aðferðina (e. method) svo að hvert stak í fylkinu sé af tegundinni float32. Að lokum skulið þið nota nbytes eigindina til þess að komast að því hvað fylkið tekur upp mörg bæti í minni.
