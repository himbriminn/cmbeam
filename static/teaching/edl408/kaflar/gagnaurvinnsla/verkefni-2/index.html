Verkefni 2¶

Skriftan fyrir neðan sýnir tímaröð spennumælinga (V) sem er lýst með sínusbylgju en því miður eru tímapunktarnir óreglulegir (það er ekki fast tímabil á milli mælipunkta). Í þessu verkefni ætlum að nota margliðubrúun til þess að búa til nýja tímaröð með tímapunktum sem eru með reglulegu bili á milli mælieining ($t_{i+1} - t_i = \mathrm{fasti}$).

import numpy as np
import matplotlib.pyplot as plt

N = 50
np.random.seed(42)
tsteps = np.abs(np.random.normal(loc=0., scale=1.0, size=N+1))
t_irreg = np.cumsum(tsteps)
t = np.linspace(0, np.max(t_irreg), 10*N)

error = np.random.normal(loc=0., scale=0.05, size=N+1)
series_irreg = np.sin(t_irreg) + error
series = np.sin(t)

plt.plot(t, series, lw=0.5)
plt.scatter(t_irreg, series_irreg, s=16, color='tab:orange')
plt.xlabel('Tími [s]')
plt.ylabel('Spenna [V]')
plt.show()
