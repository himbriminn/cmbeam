Legendre margliður¶

Adrien-Marie Legendre (1752-1833) var franskur stærðfræðingur sem vann meðal annars við að þróa aðferð minnstu fervika (e. least squares). Vatnslitamyndin hér fyrir ofan virðist vera ein af afar fáum myndum sem til eru af Legendre.

Við kynnumst Legendre-margliðurnar í fyrirlestraglósunum sem fylgja þessari viku. Fyrstu tvær Legendre-margliðurnar $P_n(x)$ eru:

$$ P_0(x)=1, \qquad P_1(x)=x. $$

Þar að auki má nota þrepaformúlu sem sýnir að fyrir $n \ge 1$ gildir:

$$ (n+1)P_{n+1}(x) = (2n+1)xP_n(x) - nP_{n-1}(x). $$

Legendre margliðurnar eru hornréttar á bilinu $[-1,1]$, þetta þýðir að:

$$ \int_{-1}^{1} P_m(x)P_n(x)\,dx = 0 \qquad \text{ef } m \ne n. $$

Við skulum byrja á því að skilgreina Python fall sem skilar Legendre-margliðu af stigi $n$:

def legendre(n, x):
    '''
    Reiknar Legendre-margliðuna P_n(x) með rakningarformúlu.
    Breytan x má vera tala eða NumPy-fylki.
    '''
    x = np.asarray(x)

    if n == 0:
        return np.ones_like(x, dtype=float)
    if n == 1:
        return x.astype(float)

    Pnm1 = np.ones_like(x, dtype=float)  # P_0
    Pn = x.astype(float)                 # P_1

    for k in range(1, n):
        Pnp1 = ((2*k + 1) * x * Pn - k * Pnm1) / (k + 1)
        Pnm1, Pn = Pn, Pnp1

    return Pn

Spurning 1¶

Hversu oft skiptir fallið $P_n(x)$ um formerki á bilinu $x\in [-1,1]$? Hvernig breytist sveiflutíðni fallsins $P_n(x)$ með stuðlinum $n$?

Innfeldi¶

Við skilgreinum innfeldi:

$$ \langle P_m, P_n \rangle = \int_{-1}^{1} P_m(x)P_n(x)\,dx. $$

Umfjöllun í Boas 12.7 sýnir okkur að Legendre föllin mynda þverstæðan grunn, þ.e.a.s.

$$ \langle P_m, P_n \rangle = \int_{-1}^{1} P_m(x)P_n(x)\,dx = 0 \quad \text{nema}\: n = m. $$

Kóðinn hér fyrir neðan notar trapisuheildun til þess að reikna innfeldi fallanna $P_n(x)$ og $P_m(x)$. Við ættum að sjá að öll stök í fylkinu G eru núll utan stök á hornalínunni.

def inner_product(m, n, x):
    pm = legendre(m, x)
    pn = legendre(n, x)
    return np.trapezoid(pm * pn, x)

x = np.linspace(-1, 1, 5000)

N = 6
G = np.zeros((N, N))

for m in range(N):

Föll nálguð með Legendre-röð¶

Það er hægt að nálga alls konar föll sem eru skilgreind á bilinu $[-1,1]$ með Legendre-margliðum og alveg eins og í skammtafræði má finna stuðlana með því að reikna innfeldi fallsins sem á nálga við Legendre-margliðurnar.

Umfjöllun um innfeldi þessara falla má m.a. finna í Boas Köflum 12.6-12.8.

Athugið að við getum notað nákvæmlega sömu aðferð til þess að nálga fall með sínus- eða kósínus-röð.

Kóðinn hér fyrir neðan hjálpar okkur að reikna Legendre sundurliðun (e. decomposition) fyrir ótiltekið fall $f(x)$.

def legendre_coeff(f, N, x):
    '''
    Finnur stuðla á nálgun Legendre-margliðu  við fallið f(x)

    f: Eitthvert fall
    N: Stig Legendre-margliðurnar
    x: Inntaksbreytan [NumPy-vigur]
    '''

    coeff = np.zeros(N)

    fx = f(x)
    for n in range(N):
        pn = legendre(n, x)
        coeff[n] = (2*n + 1)/2 * np.trapezoid(fx * pn, x)

    return coeff

def legendre_roed(coeff, x):
    '''
    Reiknar summu Legendre-margliða

    coeff: Stuðlar Legendre-margliða [NumPy-vigur]
    x: Inntaksbreytan [NumPy-vigur]
    '''
    y = np.zeros_like(x, dtype=float)

    for n, a in enumerate(coeff):
        y += a * legendre(n, x)

    return y

Tvívíð föll og Legendre margliður¶

Það er hægt að nota þverstæðan fallagrunn eins og Legendre margliðurnar til þess að liða upp margvíð föll, t.d. svarthvítar myndir.

Byrjum á því að skilgreina fall sem er summa Legendre margliða:

$$ I(x,y) = \sum_{m=0}^{M}\sum_{n=0}^{N} a_{mn}\,P_m(x)\,P_n(y) $$

þar sem $a_{mn}$ eru stuðlar sem við mátum við gögn og $P_m(x)$ og $P_n(y)$ eru Legendre margliður af stigi $m$ og $n$.

Nú skulum við skilgreina fall sem reiknar tvívíða Legendre liðun á ótiltekinni (svarthvítri) mynd. Við reiknum stuðlana í þessari liðun með:

$$ a_{mn} = \frac{2m+1}{2}\frac{2n+1}{2} \int_{-1}^{1}\int_{-1}^{1} I(x,y)\,P_m(x)\,P_n(y)\,dx\,dy $$

þar sem $I(x,y)$ er myndin sem við erum að reyna að lýsa og stærðirnar $(2m+1)/2$ og $(2n+1)/2$ staðla stuðlana (sjá Boas 12.8).

Við þurfum að skilgreina nokkur föll fyrir þetta verkefni:

  • legendre_table: Býr til fylki af Legendre margliðum
  • legendre_2d_decompose: Reiknar stuðla fyrir tvívíða Legendre liðun
  • legendre_2d_reconstruct: Teiknar upp mynd frá stuðlum

Við ráðumst í það verkefni í næstu þremur kóðablokkunum hér fyrir neðan:

def legendre_table(N, x):
    '''
    Notar þrepaformúlu til þess að reikna
    Legendre margliðurnar P_0(x), ..., P_N(x) sem fylki af stærð (N+1, len(x))

    N er stig margliðunnar
    x er inntaksbreytan
    '''
    x = np.asarray(x)
    P = np.zeros((N + 1, x.size), dtype=float)
    P[0] = 1.0
    if N >= 1:
        P[1] = x

    for n in range(1, N):
        P[n + 1] = ((2*n + 1) * x * P[n] - n * P[n - 1]) / (n + 1)

    return P

def legendre_2d_decompose(img, x, y, M, N):
    '''
    Reiknar stuðla, a[m, n], fyrir tvívíða Legendre liðun á mynd img(y, x).

    Breytur
    ----------
    img : 2D fylki af stærð (len(y), len(x))
        Svarthvít mynd.
    x, y : 1D vigure
        Hnit á bilinu [-1, 1].
    M, N : int
        Stig Legendre margliðunnar meðfram x og y.

    Skilar
    -------
    A : 2D fylki, stærð (M+1, N+1)
        Legendre stuðlarnir.
    Px : 2D fylki, stærð (M+1, len(x))
    Py : 2D fylki, stærð (N+1, len(y))

    '''

    Px = legendre_table(M, x)   # stærð (M+1, nx)
    Py = legendre_table(N, y)   # stærð (N+1, ny)

    A = np.zeros((M + 1, N + 1), dtype=float)

    # First project along x, then along y
    for m in range(M + 1):
        for n in range(N + 1):
            integrand = img * Px[m][None, :] * Py[n][:, None]

            # double integral: integrate over x, then y
            #val = np.trapz(np.trapz(integrand, x, axis=1), y)
            val = np.trapezoid(np.trapezoid(integrand, x, axis=1), y)

            A[m, n] = ((2*m + 1) / 2) * ((2*n + 1) / 2) * val

    return A, Px, Py

def legendre_2d_reconstruct(A, Px, Py):
    '''
    Teiknar upp mynd frá 2D Legendre stuðlum sem eru gefnir sem inntaksbreytur

    A : 2D fylki, stærð (M+1, N+1)
    Px: 2D fylki, stærð (M+1, nx)
    Py: 2D fylki, stærð (N+1, ny)

    Skilar
    -------
    img_rec : 2D fylki, stærð (ny, nx)

    '''
    ny = Py.shape[1]
    nx = Px.shape[1]
    img_rec = np.zeros((ny, nx), dtype=float)

    for m in range(A.shape[0]):
        for n in range(A.shape[1]):
            img_rec += A[m, n] * Py[n][:, None] * Px[m][None, :]

    return img_rec
