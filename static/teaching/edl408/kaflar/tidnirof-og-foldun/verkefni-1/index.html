Verkefni 1¶

Við sáum Hann síunargluggann í Jupyter vinnubókinni fyrir Viku 4 en núna ætlum við að skoða stillanlegan síunarglugga, svokallaðan Tukey glugga.

Ath: Það má líka nota orðið síunarkjarna (e. filtering kernel). Orðin gluggi og kjarni þýða það sama í þessu samhengi.

Tukey sían / glugginn er skilgreind samkvæmt

$$ w(n)= \begin{cases} \frac{1}{2}\left[1+\cos\!\left(\pi\left(\frac{2n}{\alpha(N-1)}-1\right)\right)\right], & 0 \le n < \frac{\alpha(N-1)}{2} \\[6pt] 1, & \frac{\alpha(N-1)}{2} \le n \le (N-1)\left(1-\frac{\alpha}{2}\right) \\[6pt] \frac{1}{2}\left[1+\cos\!\left(\pi\left(\frac{2n}{\alpha(N-1)}-\frac{2}{\alpha}+1\right)\right)\right], & (N-1)\left(1-\frac{\alpha}{2}\right) < n \le (N-1) \end{cases} $$

Það eru tvær frjálsar breytur í jöfnunni fyrir þennan glugga, $\alpha$ og $N$. Við ætlum að skoða þær gera í skrefinu fyrir neðan.

Skref 1¶

Við skulum byrja á því að skilgreina hjálparfall sem við notum til þess að teikna upp Tukey gluggann / földunarkjarnann (sjá blokk fyrir neðan).

Takið eftir np.fft.fft(window, 2048) skipuninni í kóðanum hér fyrir neðan.

Spurning: Af hverju erum við bólstra / fylla (e. padding) vigurinn okkar áður en að við reiknum þessa Fourier-ummyndun?

def plot_tukey(alpha, N=51):

    # Scipy er búið að skilgreina fallið hér fyrir ofan
    window = signal.windows.tukey(N, alpha=alpha)

    # Skilgreinum myndina
    plt.figure(figsize = [10,3])

    # Skilgreingum vinstri gluggann og merkjum
    plt.subplot(1,2,1)
    plt.plot(window)
    plt.title('Tukey gluggi')
    plt.ylabel('Styrkur')
    plt.xlabel('Númer staks á tímaás')

    plt.subplot(1,2,2)
    # Lítum á Fourier-ummyndun gluggans
    A = np.fft.fft(window, 2048) / (len(window)/2.0)
    freq = np.linspace(-0.5, 0.5, len(A))

    # Við margföldum með 20 en ekki 10 þar sem við erum að skoða 'orku' gluggans
    # Sjá t.d. umfjöllun um reglur Parsevals
    response = 20 * np.log10(np.abs(np.fft.fftshift(A / abs(A).max())))
    plt.plot(freq, response, color='tab:orange')
    plt.axis([-0.5, 0.5, -120, 0])

    # Merkjum hægri gluggann
    plt.title('Tukey gluggi á tíðniás')
    plt.ylabel('Staðlaður styrkur [dB]')
    plt.xlabel('Tíðni [lotur per tímalengd]')
    plt.grid()

    plt.tight_layout()
    plt.show()

    return window

Ímyndið ykkur nú að tímaraðirnar sem við erum að skoða séu einmitt að lýsa spennu sem fall af tíma. Þá er aflið í tímaröðinni í réttu hlutfalli við spennuna í öðru veldi.

Skref 2¶

Í hjálparfallinu plot_tukey sem við skilgreindum í Skrefi 1 bólstruðum við gögnin til að fá hærri tíðniupplausn. Hér fyrir neðan skulum við sleppa því og horfa aðeins á síunargluggana og samsvarandi Fourier-ummyndanir.

ATH: Við hliðrum stöplunum örlítið eftir lóðrétta ásnum svo að þeir renni ekki saman þegar við skoðum myndina hér fyrir neðan.

def plot_time_freq_multi(t, y, alpha, N, idx=0, axs=None, normalize=True):

    # Reiknum strjála Fourier-ummyndun og tölugildi þeirrar ummyndunar
    freq = np.fft.fftfreq(t.size, d=t[1]-t[0])
    freq_shift = np.fft.fftshift(freq)
    Y_FFT = abs(np.fft.fft(y))
    Y_FFT = np.fft.fftshift(Y_FFT)

    # Stöðlum
    if normalize:
      Y_FFT /= np.max(Y_FFT)

    # Skilgreinum grafið ef að þetta er í fyrsta skipti sem við keyrum fallið
    if idx == 0:
        fig, axs = plt.subplots(1, 2, figsize=(14, 5))

    # Teiknum stöplarit fyrir síunargluggann (Ath: lóðrétta hliðrun fyrir sýnileika)
    p = axs[0].plot(t, y - 0.005*idx, lw=0, marker='.', ms=6,
                    label=r'$\alpha$ = {}, $N$ = {}'.format(alpha, N))

    # Merkjum ásana
    axs[0].set_title('Raunás (e. real domain)')
    axs[0].set_xlabel('Númer staks á tímaás')
    axs[0].set_ylabel('Styrkur')
    axs[0].legend()

    # Teiknum stöplarit fyrir Fourier-ummyndun síunargluggans (Ath: lóðrétta hliðrun fyrir sýnileika)
    markerline, stemline, baseline = axs[1].stem(freq_shift, 20*np.log10(Y_FFT) - 0.5*idx,
        'k', markerfmt='{:s}'.format(p[0].get_color()), bottom=-100)

    plt.setp(stemline, linewidth = 1)
    plt.setp(markerline, markersize = 4)

    axs[1].set_title('Tíðniás (e. frequency domain)')
    axs[1].set_xlabel('Tíðni')
    axs[1].set_ylabel('Staðlaður styrkur [dB]')

    return axs

Skref 3 — Gervitímaröð með suði¶

Skilgreinum enn eina ferðina einhvers konar gervitímaröð með suði:

np.random.seed(3)
time = np.linspace(0, 5, 512)
y_sine = 2*np.sin(2 * np.pi * 0.5 * time)
y_cos = 1.5*np.cos(2 * np.pi * 2.5 * time)
y_trend = (0.5 * time)**2
y_noise = 0.8 * np.random.randn(len(time))
y_signal = y_sine + y_cos + y_trend
noisy_signal = y_signal + y_noise
