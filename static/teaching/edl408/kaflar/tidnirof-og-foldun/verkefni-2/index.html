Verkefni 2¶

Við erum búin að sjá að:

  • Hægt er að nota földun eftir raunás til þess að sía gögn
  • Földun eftir raunás er jafngild margfeldi á tíðniás

Verkefni 0 sýndi jafnframt að földun er tímafrek aðgerð. Hér ætlum við að reikna tímann sem að það tekur að sía einvíð gögn með aðferðunum tveimur sem við höfum kynst.

Þegar þið hafið tíma þá legg ég til að þið kíkið á þetta myndaband frá 3Blue1Brown.

Við höldum áfram að vinna með þessa blessuðu gervitímaröð:

np.random.seed(3)
# Hjálparfall sem býr til gervigögn
def generate_data(n):
    N = 2**n
    t = np.linspace(0, 5, N)
    y_sine = 2*np.sin(2 * np.pi * 0.5 * t)
    y_cos = 1.5*np.cos(2 * np.pi * 2.5 * t)
    y_trend = (0.5 * t)**2
    y_noise = 0.8 * np.random.randn(len(t))
    y_signal = y_sine + y_cos + y_trend
    noisy_signal = y_signal + y_noise

    return t, y_signal, y_noise, noisy_signal

Teiknum upp graf sem sýnir hrein gögn og gögn með suði fyrir tímaröð sem hefur $N = 2^{14} = 16.384$ stök.

Í kóðanum hér fyrir neðan ætlum við að vinna með Tukey síunarglugga sem við skilgreindum í fyrri verkefnum.

# Skilgreinum Tukey síuunargluggann okkar
N = 501
alpha = 0.7
window = signal.windows.tukey(N, alpha=alpha)

Skoðið kóðann hér fyrir neðan mjög vandlega.

Við skulum byrja á því að nota Tukey síunarglugga sem hefur lengdina $N = 501$ (sbr. skilgreiningu hér fyrir ofan).

Kóðinn gerir þrjá hluti:

  1. Skilgreinir for-lykkju sem breytir fjölda staka í tímaröðinni
  2. Teiknar graf af upprunalegu gögnunum og síuðu gögnunum
  3. Reiknar tímann sem það tekur að sía gögnin með tveimur aðferðum og prentar á skjáinn
plt.figure(figsize=[9,6])
for idx, n in enumerate([14, 15, 16, 17, 18]):

    print('N = {}'.format(2**n))
    t, y_signal, y_noise, noisy_signal = generate_data(n)

    if idx == 0:
        plt.plot(t, y_signal + y_noise, 'k', lw=1, label='Gögn með suði')
        plt.plot(t, y_signal, 'tab:blue', lw=3, label='Upprunaleg gögn')

    ## Síum gögnin með Fourier-ummyndun (endurtökum M sinnum og reiknum miðgildi)
    M = 20
    ts1 = np.nan * np.ones(M)
    for i in range(M):
        t0 = time.perf_counter()
        # Reiknum Fourier-ummyndun gluggans og stöðlum
        response = np.fft.fft(window, len(t))
        response = np.abs(response / abs(response).max())

        Y = (np.fft.fft(noisy_signal))
        y_tukey = np.fft.ifft(Y * response)
        t1 = time.perf_counter()
        ts1[i] = t1-t0

    print('  Fourier filter: t = {:.4f}'.format(np.median(ts1[i])))

    ## Földun eftir raunás (endurtökum M sinnum og reiknum miðgildi)
    ts2 = np.nan * np.ones(M)
    for i in range(M):
        t0 = time.perf_counter()
        output = np.convolve(noisy_signal, window, mode='same')
        t1 = time.perf_counter()
        ts2[i] = t1-t0

    print('  Real space filter: t = {:.4f}'.format(np.median(ts2[i])))
    print('  Speedup (Real space / Fourier space): {:.2f}'.format(np.median(ts2[i]) / np.median(ts1[i])))

    if idx == 0:
        plt.plot(t, np.real(output)/np.sum(window), 'tab:red',
                 linestyle='--', lw=3, alpha=0.8, label='Földuð eftir raunás')
        plt.plot(t, np.real(y_tukey), 'tab:orange', linestyle='--', lw=3, alpha=0.8,
                 label='Með Fourier ummyndun')

plt.xlabel('Tími [s]')
plt.ylabel('Merki')
plt.legend()
plt.show()
